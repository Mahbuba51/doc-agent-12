| 0 Frame | Precision-first document-understanding agent for Land Registry Archives & Legal Aid: answer questions from scanned historical Dolils (Bangla-English handwritten deeds) with page citations. Headline target: Exact Match ≥95% on verifiable legal fields, F1 ≥0.92 overall. | Bangla Handwritten Dolil Dataset (Mendeley, CC BY 4.0, DOI 10.17632/yk3c3xy9vm.1): 653 scanned JPEGs, all 653 usable (an earlier 609-page count wrongly excluded 44 files by a file-size heuristic — corrected after direct visual + integrity-check verification, see `notebooks/eda.ipynb`), ~95k words (est., finalized in A2), 2.33GB. Target split 70/15/15 by deed; a page-order placeholder split is in `data/splits.json` pending real deed-serial grouping (hand-built `deed_group` CSV, in progress). | No model at this stage — framing only. Downstream: DocLayout-YOLO (layout), Qwen2.5-VL + GraDeT-HTR (reading), BGE-M3 (embed), Qwen3-4B-AWQ (agent controller). | Desk officers currently cross-reference paper Dolils manually — slow and error-prone with real legal consequences; the tool's source of truth is the scanned page itself, so grounded citation (not web search / general chat) is the right fit. | Agent must abstain rather than guess when evidence is weak; coverage is traded for trustworthiness given the precision-first NFR. | Justified against our own corpus (Section 1-4 of A1 form): domain, speciality, and NFR each point to specific pages/fields, not generic claims. | Offline batch ingest, online agent serving later (A4). Azure GPU VM (Standard_NC4as_T4_v3) planned for the served stack. | Track corpus version, split seed, and config snapshot via MLflow (Stage 8+); reproducible-by-corpus is the grading bar. |
| 1 Ingest+Enhance | Load and clean all 653 usable scanned Dolil pages so downstream layout/reading stages get a legible, unmodified-evidence image. | Same corpus; input is raw JPEGs in `data/raw/`, output is deskewed/denoised/binarized variants plus the untouched original+greyscale (kept as fallback since binarization can drop faint seals/matras). | Classical pipeline only: Pillow + OpenCV. No VAE/diffusion generative repair — rejected because a generative model could reconstruct, reshape, or remove a handwritten stroke and change a legally significant plot number, name, date, or amount. | Validate via a real integrity check (opens as a valid image, ≥200px both dimensions) — NOT a file-size threshold, which we tried first and it wrongly flagged 44 legible pages as corrupt; convert to greyscale; estimate skew via Hough/projection-profile search in [-4°,+4°] and rotate (fill=255); light 3x3 median denoise + non-local-means for show-through; Sauvola adaptive threshold (window 15, k=0.2, R=128) for a binary copy; scan-quality proxy = normalized high-pass blur variance (radius 3, /40.0), flag <0.35 as low-legibility; Unicode NFC text normalization + Bangla↔ASCII digit mapping downstream. | Deterministic, rule-based Stage 1 (no training loss) feeding Stage 2 layout detection; conservative parameters chosen to preserve thin strokes over aggressive cleanup. | Verified in `notebooks/eda.ipynb`: file counts, legibility-band histogram, pHash near-duplicate leakage check, before/after examples on representative pages (`dolil_13`, `dolil_20`, `dolil_11`). | Runs offline as a one-time batch job (`scripts/build_index.sh` upstream step) before the agent is served, avoiding repeated expensive image ops per query. | Preprocessing config (skew range, denoise, Sauvola params, quality threshold) is versioned alongside the corpus snapshot so a preprocessing change is traceable to its effect on downstream Exact Match. |
